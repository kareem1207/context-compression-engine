      This page runs CCE Lite, a small version of the engine written in JavaScript that matches on shared words. The Python version understands paraphrases too. In our tests CCE finds facts said long ago as reliably as ordinary search while sending far fewer tokens than the whole chat; see the benchmarks and their limits.
