Context Compression Engine

Give an AI the right memory, not the whole chat.

GitHub

Long conversations get expensive and slow because the model rereads everything. CCE splits a chat into topics, summarises each one, and for every new question sends only the relevant topics plus the last few messages.

This page is CCE Lite: the same pipeline written in plain JavaScript, running in your browser. Nothing you paste is uploaded. The Python engine uses a neural sentence model for topic detection; Lite uses a lightweight word-hashing embedder, so it is best on keyword-rich text.
